Guards an action behind a recent two factor check. Answers true when the session passed one inside `two_factor_freshness_seconds`, and for every account that carries no two factor at all.

public requireFreshTwoFactor([int|null $freshnessSeconds = null ][, bool $boolResult = false ]) : bool

Without $boolResult a stale session is answered with a json error carrying twoFactorRenew, which Z.js turns into the two factor modal. Pass true to answer the client yourself instead:

if(!$req->requireFreshTwoFactor(boolResult: true)) {
    return $res->error("Two factor required", ["twoFactorRenew" => true]);
}
Parameters
$freshnessSeconds : int|null = null

How recent the check has to be, or null for the configured window

$boolResult : bool = false

Return the answer rather than ending the request

Return values
bool —

Whether the session is fresh enough
