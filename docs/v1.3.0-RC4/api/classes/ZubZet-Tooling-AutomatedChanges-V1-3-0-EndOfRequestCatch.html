EndOfRequestCatch
in package
  • Application

EndOfRequestCatch.php : 12

Finds the catches of \Throwable or \Error that also catch the end of a request. Since 1.3.0 a call that ends the request throws EndOfRequest (an \Error) instead of calling exit, so such a catch keeps the action running.

A try with an earlier catch of EndOfRequest is fine and not reported.
