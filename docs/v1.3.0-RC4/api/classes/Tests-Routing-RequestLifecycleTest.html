RequestLifecycleTest extends ApplicationTestCase
in package
  • Application

RequestLifecycleTest.php : 20

Whole requests through the real router: how an action is found, what a guard does to it, where it ends and what runs around it. The application lives in fixtures/application.

These cases used to need a browser test, because an action that answered ended the process. What a client sees of an answer (headers, cookies, status code) is still asserted by the e2e suite.
